# Himani Gusain — Portfolio

Personal portfolio site: projects, skills, and contact — static, fast, and deployed for sharing with a single link.

## Live site

**[Open the portfolio](https://portfolio-himanigusain.vercel.app/)**

## Tech stack

- **HTML5** — structure and content  
- **CSS3** — layout, custom properties, animations, responsive styling  
- **JavaScript** — interactions (vanilla, no framework)  
- **Google Fonts** — Syne, Outfit, Instrument Serif  

## Run locally

Open `index.html` in a browser, or use a simple local server (e.g. VS Code *Live Server*) so all paths behave like production.
